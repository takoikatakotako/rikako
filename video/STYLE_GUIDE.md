# 動画デザインガイド v0.1

化学・IT・制作記録を同じチャンネルで扱うための共通ルール。最初の数本を見比べてから更新する。

## 色

| 用途 | 色 | 値 |
| --- | --- | --- |
| 暗い背景・濃い文字 | 深緑 | `#102B25` |
| 明るい背景 | 生成り | `#F4F0E7` |
| 暗い背景上の文字・カード | 白 | `#FFFCF7` |
| 共通の強調・正解 | 黄緑 | `#CDEB79` |
| ITの補助色・図解 | 水色 | `#50BDD1` |
| 同じ要素・注意点 | 琥珀色 | `#F4C17E` |
| 補足文字 | 灰緑 | `#66776D` |

深緑と生成りを基本にし、分野の違いは小さな補助色と見出しで表す。化学動画の採用版と共通の色を使い、ITだけが別ブランドに見えないようにする。強調色を同じ画面で増やしすぎない。

## 画面

- 縦型 `1080 × 1920`、30 fps。重要な文字と図は左右70 px以上、上下ではおおむね170〜1660 pxの範囲に置く。最下部は投稿アプリのUIと重なりやすいため、補助情報だけにする。
- 常時表示のヘッダーやジャンル表示は企画ごとに判断する。使う場合は背景画像に描き込まず、Daihon の `video.overlays` で重ねる。
- 日本語の大見出しは80〜110 px、説明文は48〜70 pxを目安にする。1画面に伝えることは一つ。
- クイズは「問い → 選択肢 → 考える3秒 → 答え → 理由 → 一言で復習」を基本形にする。選択肢の正誤は知識として正確なものだけを使う。
- `video/index.html` は制作物の一覧。各動画の素材・台本・書き出しは企画フォルダ内に置く。

## キャラクター

- 大きな立ち絵の理科子さんやカメさんは問い、答え、締めなどの節目に登場させる。図解の中央や選択肢には重ねない。
- カメさんの共通素材は [`assets/rikako-turtle-v1.png`](assets/rikako-turtle-v1.png)。[`assets/rikako-standing.png`](assets/rikako-standing.png)のカメを参照して画像生成で透過の単体素材にしたもの。
- 小さな飾りとして置く場合も、顔と甲羅が読み取れる大きさにする。台詞や大事な図の上には置かない。
- アプリアイコンは [`assets/`](assets/README.md) に化学版・ITパスポート版を保存。文字入りなので、締め画面やサムネイルで大きめに使う。

## 音声と確認

- 当面の共通音声は Vertex AI Gemini TTS の `Sulafat`、日本語 `ja-JP`。話し方は明るく自然で、ややゆっくり明瞭にする。
- Daihon の `movie.yml` を台本と合成設定の正本にする。生成前に `daihon check`、書き出し後に絵コンテと動画を確認する。
- 出典のある学習内容は、各企画の `README.md` に参照資料を記録する。公開前に内容・字幕・読み上げ・投稿先での表示を再確認する。
