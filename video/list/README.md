# 新しい動画の保存場所

新規企画は `YYYY-MM-DD-企画名/` の1フォルダに台本、素材、生成スクリプト、制作メモをまとめる。Daihon を使う動画はそのフォルダの直下に `movie.yml` を置く。日付は着手日とし、公開日や更新日が変わってもフォルダ名は変えない。

例：[`2026-10-25-pilot-salt-sand/`](2026-10-25-pilot-salt-sand/README.md)、[`2026-10-26-pilot-chromatography/`](2026-10-26-pilot-chromatography/README.md)、[`2026-11-09-it-passport-mfa/`](2026-11-09-it-passport-mfa/README.md)

日付だけのフォルダにはしない。同じ日に複数の企画を始めても区別でき、フォルダ一覧で内容が分かるようにする。新規企画の分野は[`../index.html`](../index.html)の表で管理する。

化学の試作も含め、動画はこのディレクトリにまとめる。新しい企画を作ったら[`../index.html`](../index.html)の表に1行追加する。
