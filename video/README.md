## 制作方針の仮決め

まず共通のカメ素材を使って数本作り、問い・図解・ナレーションの型を固める。カメは出題、正解発表、締めで使い、実験・粒子の説明中は図を主役にする。立ち絵版はインクの色の旧版に残してある。

Live2Dに進むなら、表情・口・髪・手などを分けた原画とモデリングが必要。現在リポジトリにあるのは統合済みの透過PNGなので、GPUだけでは同じ絵から自然なLive2Dモデルを作れない。動画の型が定まり、理科子さんが話す場面を増やしたくなった時点で、レイヤー原画の制作から始める。

公開後は冒頭3秒の視聴維持、平均視聴時間、完走率、プロフィールから問題ページへの流入を見て、キャラクター演出に制作時間をかける価値を判断する。

現在の試作はいずれもローカルのみで、未投稿。
