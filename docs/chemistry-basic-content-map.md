# 化学基礎 カリキュラム・動画ネタ一覧

最終確認: 2026-10-25。高校「化学基礎」の学習範囲を、ショート動画の企画に使える形へ整理したもの。

**基準:** 文部科学省 [高等学校学習指導要領（平成30年告示）「化学基礎」](https://www.mext.go.jp/content/20220324-mxt_kouhou02-000021499_1.pdf) の pp.113–115。下表の14項目は学習指導要領の見出しに沿う。「できるようにすること」と動画の問いは企画用の要約・提案。

**問題リンク:** 理科子の「化学基礎」から、内容を確認して代表例を1題ずつ選んだ。全1000問を単元別に分類したものではない。公開・再編集前には問題文と説明を再確認する。

## 次に作る順番の案

1. **インクの色は1色？** — 紙上で変化を見せやすい。クロマトグラフィー（[問679](https://chemistry.rikako.org/questions/679/)）
2. **水とエタノール、どう分ける？** — 蒸留装置を図解できる（[問680](https://chemistry.rikako.org/questions/680/)）
3. **ドライアイスが消える理由** — 状態変化の映像化に向く（[問683](https://chemistry.rikako.org/questions/683/)）
4. **Naが Na⁺ になると電子は？** — 理科子さんに粒子を指さしてもらえる（[問692](https://chemistry.rikako.org/questions/692/)）
5. **金属が電気を通す理由** — 自由電子を動かして説明できる（[問674](https://chemistry.rikako.org/questions/674/)）
6. **水素と酸素の比** — 分子の数を画面上で数えられる（[問703](https://chemistry.rikako.org/questions/703/)）

**制作メモ:** 1本では原則「問い1つ・理由1つ・画面上の変化1つ」に絞る。理科子さんのLive2Dモデルができたら、出題・正解発表・締めの共通演出に使い、単元ごとの図だけを差し替える。
