# プライバシーポリシー

最終更新日：2026年8月8日

本プライバシーポリシーは、当アプリ（以下「本アプリ」）における個人情報の取り扱いについて説明します。

## 収集する情報

本アプリは以下の情報を収集します。

- **デバイス識別子**：アプリの利用状況を管理するために、端末ごとに発行される匿名IDを使用します。
- **学習データ**：回答履歴、正誤情報などの学習に関するデータを収集します。
- **メールアドレス**：アカウント登録（任意）をした場合に、ログインと機種変更時の学習データの引き継ぎのために収集します。
- **利用状況データ**：アプリの起動、画面の閲覧、機能の利用などの操作イベントを、利用状況の分析のために収集します。個人を特定する情報や入力内容そのものは含みません。
- **AIチャットの入力内容**：AI機能をご利用の際に入力・送信された質問文を、回答の生成のために収集します。
- **お問い合わせ内容**：お問い合わせフォームから送信された内容を収集します。

## 情報の利用目的

収集した情報は以下の目的で利用します。

- アプリの機能提供（学習履歴の保存・表示、AIチャットの回答生成）
- アプリの改善および不具合の対応、利用状況の分析
- お問い合わせへの返答

## 外部サービスの利用

本アプリは、機能の提供および改善のために以下の外部サービスを利用しており、その運営に必要な範囲で情報を送信します。各サービスにおける情報の取り扱いは、それぞれの提供者のプライバシーポリシーに従います。

- **Google アナリティクス（Firebase Analytics／Google LLC）**：利用状況データおよび匿名の識別子を送信し、アプリの利用状況の分析・改善に利用します。広告用の識別子（IDFA）は利用しません。
- **Firebase Crashlytics（Google LLC）**：アプリが異常終了した際のクラッシュ情報（発生箇所、端末の機種・OSバージョン、アプリのバージョンなど）を送信し、不具合の把握と修正に利用します。個人を特定する情報は含めません。
- **OpenAI（OpenAI, L.L.C.）**：AIチャット機能で入力された質問文を、回答の生成のために送信します。
- **Amazon Web Services（AWS）**：データの保存・配信などのインフラとして利用します。

## 情報の第三者提供

収集した情報は、上記「外部サービスの利用」に記載する場合および法令に基づく場合を除き、第三者に提供しません。

## 情報の管理

収集した情報はAWSのサーバー（アジア太平洋リージョン）を中心に保存し、適切なアクセス制御のもとで管理します。

## アカウントとデータの削除

アカウント登録（メールアドレス）をした方は、アプリの設定画面またはアカウントポータル（https://account.rikako.org/delete ）からいつでもアカウントを削除できます。削除すると、アカウント、登録メールアドレス、アカウントに紐付いたすべての端末の学習データ（回答履歴、設定、引き継ぎ用トークン）がただちに削除されます。

削除後、削除処理の整合性を保つ目的で、アカウントの内部識別子（メールアドレスや氏名を含まない、認証基盤が発行した ID）のみを保持し、認証基盤側の削除完了から最長 7 日で自動的に削除します。この期間中に同じ識別子でデータが再作成されることはありません。

アカウント登録をしていない（匿名で利用している）方のデータは端末ごとの匿名 ID にのみ紐付いており、アプリを削除すると新しい匿名 ID からは参照できなくなります。

ログインできない等の理由で上記の方法が使えない場合は、登録したメールアドレスからお問い合わせください。本人確認のうえ手動で削除します。
